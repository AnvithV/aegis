Candidates

Candidate endpoints expose per-person evidence trails and allow analysts to attach free-text notes to any candidate across queries.

GET /v1/candidates/{uuid}/evidence​

Fetch the full evidence trail for a candidate — every artifact (publications, grants, trials, patents) associated with them, with source attribution and direct links.

Auth required: Yes

Path Parameters​

ParamDescription
uuidThe candidate_uuid from a query result

Response — 200 OK​

Evidence Item Fields​

FieldDescription
sourceWhich database this came from: pubmed, icite, reporter, ctgov, openalex, notes
artifact_typepmid, pmid_rcr (iCite RCR score), grant_id, nct_id, patent_id
artifact_idThe raw identifier (PMID, grant number, NCT ID, etc.)
titleHuman-readable label
urlDirect link to the source record
dateISO 8601 date string, or null if unknown
detailThe verbatim evidence trail string stored during ingestion

Notes​

  • Evidence items are tagged by source, enabling the frontend to filter by tab (All / PubMed / iCite / NIH Grants / Trials / Notes).
  • iCite RCR (Relative Citation Ratio) scores are stored as artifact_type = "pmid_rcr" with artifact_id = "PMID:rcr=X.XXX". An RCR > 1.0 means the paper is cited more than the average NIH-funded paper in its field.
  • Evidence trails are capped at 20 items per candidate.

Errors​

StatusCondition
404No candidate with that UUID exists

POST /v1/candidates/{uuid}/notes​

Create a new analyst note on a candidate. Notes are associated with the authenticated customer (author).

Auth required: Yes

Path Parameters​

ParamDescription
uuidThe candidate_uuid to annotate

Request Body​

{
  "content": "Strong KRAS background. Has Phase 1 experience at MSKCC. Follow up on collaboration history with Amgen."
}
FieldTypeRequiredDescription
contentstring✅Free-text note content

Response — 200 OK​

{
  "id": "note_7f3e2a1b9c4d5e6f"
}

GET /v1/candidates/{uuid}/notes​

List all analyst notes for a candidate.

Auth required: Yes

Path Parameters​

ParamDescription
uuidThe candidate_uuid

Response — 200 OK​

{
  "notes": [
    {
      "id": "note_7f3e2a1b9c4d5e6f",
      "candidate_uuid": "b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6",
      "author": "frontend",
      "content": "Strong KRAS background. Has Phase 1 experience at MSKCC.",
      "created_at": "2026-04-29T15:10:00Z",
      "updated_at": "2026-04-29T15:10:00Z"
    }
  ]
}

PUT /v1/candidates/{uuid}/notes/{note_id}​

Update the content of an existing note.

Auth required: Yes

Path Parameters​

ParamDescription
uuidThe candidate_uuid
note_idThe id returned when the note was created

Request Body​

{
  "content": "Updated note text."
}

Response — 200 OK​

{
  "status": "updated"
}

DELETE /v1/candidates/{uuid}/notes/{note_id}​

Delete an analyst note.

Auth required: Yes

Path Parameters​

ParamDescription
uuidThe candidate_uuid
note_idThe note ID to delete

Response — 200 OK​

{
  "status": "deleted"
}
