Shortlists

Shortlists are named collections of candidates curated by an analyst. They are scoped per customer — each customer sees only their own shortlists.

POST /v1/shortlists​

Create a new empty shortlist.

Auth required: Yes

Request Body​

{
  "name": "KRAS Phase 2 PI Candidates",
  "description": "Shortlisted PIs for the Q3 KRAS lung cancer Phase 2 trial"
}
FieldTypeRequiredDescription
namestring✅Display name for the shortlist
descriptionstring❌Optional longer description

Response — 200 OK​

{
  "id": "sl_a1b2c3d4e5f6",
  "name": "KRAS Phase 2 PI Candidates"
}

GET /v1/shortlists​

List all shortlists for the authenticated customer.

Auth required: Yes

Response — 200 OK​

{
  "shortlists": [
    {
      "id": "sl_a1b2c3d4e5f6",
      "name": "KRAS Phase 2 PI Candidates",
      "description": "Shortlisted PIs for the Q3 KRAS lung cancer Phase 2 trial",
      "created_by": "frontend",
      "created_at": "2026-04-29T15:00:00Z",
      "member_count": 7
    }
  ]
}

GET /v1/shortlists/{shortlist_id}​

Get a shortlist and all its current members.

Auth required: Yes

Path Parameters​

ParamDescription
shortlist_idThe shortlist ID from create or list

Response — 200 OK​

{
  "id": "sl_a1b2c3d4e5f6",
  "name": "KRAS Phase 2 PI Candidates",
  "description": "Shortlisted PIs for the Q3 KRAS lung cancer Phase 2 trial",
  "created_by": "frontend",
  "created_at": "2026-04-29T15:00:00Z",
  "members": [
    {
      "candidate_uuid": "b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6",
      "added_at": "2026-04-29T15:05:00Z",
      "added_by": "frontend"
    }
  ]
}

Errors​

StatusCondition
404Shortlist not found

POST /v1/shortlists/{shortlist_id}/candidates​

Add a candidate to a shortlist.

Auth required: Yes

Path Parameters​

ParamDescription
shortlist_idThe shortlist to add to

Request Body​

{
  "candidate_uuid": "b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6"
}

Response — 200 OK​

{
  "status": "added"
}

DELETE /v1/shortlists/{shortlist_id}/candidates/{candidate_uuid}​

Remove a specific candidate from a shortlist.

Auth required: Yes

Path Parameters​

ParamDescription
shortlist_idThe shortlist
candidate_uuidThe candidate to remove

Response — 200 OK​

{
  "status": "removed"
}

DELETE /v1/shortlists/{shortlist_id}​

Delete an entire shortlist and all its members.

Auth required: Yes

Path Parameters​

ParamDescription
shortlist_idThe shortlist to delete

Response — 200 OK​

{
  "status": "deleted"
}

GET /v1/shortlists/{shortlist_id}/export​

Export the shortlist members as a CSV file download.

Auth required: Yes

Path Parameters​

ParamDescription
shortlist_idThe shortlist to export

Response — 200 OK​

Returns a text/csv file with the Content-Disposition: attachment header.

Content-Type: text/csv
Content-Disposition: attachment; filename="shortlist_sl_a1b2c3d4e5f6.csv"

CSV columns:

candidate_uuid,added_at,added_by
b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6,2026-04-29T15:05:00Z,frontend

Errors​

StatusCondition
404Shortlist not found
