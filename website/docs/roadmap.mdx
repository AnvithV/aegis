# Roadmap

## Phase Status

| Phase | Name | Status | Summary |
|-------|------|--------|---------|
| 0 | Foundation | Complete | DuckDB schema, PubMed/RePORTER/CT.gov ingestion, two-tier identity resolution, NSCLC seed cohort, archetype validation |
| 1 | Scoring | Complete | Quality prior (F1-F6), integrity gate, topical fit, recency, end-to-end ranker, audit panel, Plackett-Luce weight learning, observability |
| 2 | Multi-Population | Complete | Drug-discovery (USPTO/EPO patents, CPC-MeSH, ChEMBL), clinician (NPI, ABMS, state boards, USNWR), F7 clinician score, per-population weight vectors, specialty classifier, cross-population merge |
| 3 | Production | Complete | FastAPI + JWT auth, event-driven integrity ingestion, LLM query expansion, downstream feedback loop, geographic broadening (EPO/ERC/MRC/CIHR/KAKEN/NSFC), contestability workflow |
| 4 | Frontend + Docs | In Progress | Next.js frontend (New Query, Results, Query History), Docusaurus documentation site |

## What Has Been Built

Aegis is a fully operational researcher-ranking engine spanning 100 tasks across four completed phases:

- **25+ data sources** ingested across publications, grants, patents, clinical trials, clinician credentials, integrity databases, and taxonomy crosswalks
- **Three researcher populations** — Translational, Drug Discovery, and Clinician — each with independent weight vectors learned from expert judgments
- **Multi-component scoring** with quality prior (7 sub-score families), topical fit via MeSH vectors, recency with exponential decay, and a two-tier integrity gate
- **Production API** with JWT authentication, rate limiting, audit logging, and evidence-trail responses
- **Continuous learning** via downstream task-quality feedback (Fleiss kappa, accept rate, consensus rate) feeding into weekly Plackett-Luce weight refits
- **International coverage** across 7 non-US source clients with per-region coverage diagnostics
- **Identity resolution** unifying records across sources with deterministic and probabilistic linking

## What Is In Progress

Phase 4 is actively under development with two workstreams:

- **Next.js Frontend:** A web application giving task managers a visual interface to submit specialty queries, explore ranked candidate lists with score breakdowns and evidence trails, and review query history. The frontend includes three core screens: New Query, Results, and Query History.
- **Documentation Site:** The Docusaurus site you are currently reading, providing high-level documentation for engineers joining the team and internal stakeholders.

## What Comes Next

The following areas represent planned future work beyond Phase 4:

- **additional populations:** Expanding beyond the current three populations to cover AI/ML researchers, biostatisticians, and regulatory affairs specialists. Each new population will require population-specific data sources, weight vectors, and audit panels.
- **Deeper geographic coverage:** Increasing the non-US candidate ratio from the current ~15% toward 50%+ by adding additional international grant agencies, patent offices, and clinician registries beyond the initial seven non-US sources.
- **Code and dataset artifacts:** Integrating repositories (GitHub), data archives (Zenodo), and genomic data repositories (GEO) as evidence sources for researchers whose primary output includes software, datasets, or genomic data rather than traditional publications.
- **Enhanced feedback signals:** Expanding the downstream feedback loop to incorporate additional quality signals beyond Fleiss kappa, accept rate, and consensus rate — such as time-to-completion, revision frequency, and long-term outcome tracking.
