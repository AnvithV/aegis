# Candidates

Candidate endpoints expose per-person evidence trails and allow analysts to attach free-text notes to any candidate across queries.

---

## GET /v1/candidates/\{uuid\}/evidence

Fetch the full evidence trail for a candidate — every artifact (publications, grants, trials, patents) associated with them, with source attribution and direct links.

**Auth required:** Yes

### Path Parameters

| Param | Description |
|-------|-------------|
| `uuid` | The `candidate_uuid` from a query result |

### Response — 200 OK

```json
{
  "candidate_uuid": "b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6",
  "candidate_name": "Jane Smith",
  "evidence": [
    {
      "source": "pubmed",
      "artifact_type": "pmid",
      "artifact_id": "33521700",
      "title": "Sotorasib for Lung Cancers with KRAS p.G12C",
      "url": "https://pubmed.ncbi.nlm.nih.gov/33521700",
      "date": "2021-05-20",
      "detail": "Published 'Sotorasib for Lung Cancers with KRAS p.G12C' (PMID:33521700, 2021-05-20)"
    },
    {
      "source": "icite",
      "artifact_type": "pmid_rcr",
      "artifact_id": "PMID:rcr=4.210",
      "title": "Relative Citation Ratio",
      "url": "https://icite.od.nih.gov/analysis?pmids=33521700",
      "date": null,
      "detail": "iCite RCR: 4.210 for PMID 33521700"
    },
    {
      "source": "reporter",
      "artifact_type": "grant_id",
      "artifact_id": "R01CA123456",
      "title": "NIH R01CA123456",
      "url": "https://reporter.nih.gov/project-details/R01CA123456",
      "date": null,
      "detail": "NIH R01CA123456 (FY2023, $487,000)"
    },
    {
      "source": "ctgov",
      "artifact_type": "nct_id",
      "artifact_id": "NCT04303780",
      "title": "Phase 2 Study of AMG 510 in KRAS p.G12C Mutated NSCLC",
      "url": "https://clinicaltrials.gov/study/NCT04303780",
      "date": null,
      "detail": "PI on NCT04303780: 'Phase 2 Study of AMG 510...' (Phase 2, ACTIVE_NOT_RECRUITING)"
    }
  ]
}
```

### Evidence Item Fields

| Field | Description |
|-------|-------------|
| `source` | Which database this came from: `pubmed`, `icite`, `reporter`, `ctgov`, `openalex`, `notes` |
| `artifact_type` | `pmid`, `pmid_rcr` (iCite RCR score), `grant_id`, `nct_id`, `patent_id` |
| `artifact_id` | The raw identifier (PMID, grant number, NCT ID, etc.) |
| `title` | Human-readable label |
| `url` | Direct link to the source record |
| `date` | ISO 8601 date string, or `null` if unknown |
| `detail` | The verbatim evidence trail string stored during ingestion |

### Notes

- Evidence items are tagged by source, enabling the frontend to filter by tab (All / PubMed / iCite / NIH Grants / Trials / Notes).
- iCite RCR (Relative Citation Ratio) scores are stored as `artifact_type = "pmid_rcr"` with `artifact_id = "PMID:rcr=X.XXX"`. An RCR > 1.0 means the paper is cited more than the average NIH-funded paper in its field.
- Evidence trails are capped at 20 items per candidate.

### Errors

| Status | Condition |
|--------|-----------|
| `404` | No candidate with that UUID exists |

## POST /v1/candidates/\{uuid\}/notes

Create a new analyst note on a candidate. Notes are associated with the authenticated customer (author).

**Auth required:** Yes

### Path Parameters

| Param | Description |
|-------|-------------|
| `uuid` | The `candidate_uuid` to annotate |

### Request Body

```json
{
  "content": "Strong KRAS background. Has Phase 1 experience at MSKCC. Follow up on collaboration history with Amgen."
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `content` | `string` | ✅ | Free-text note content |

### Response — 200 OK

```json
{
  "id": "note_7f3e2a1b9c4d5e6f"
}
```

## GET /v1/candidates/\{uuid\}/notes

List all analyst notes for a candidate.

**Auth required:** Yes

### Path Parameters

| Param | Description |
|-------|-------------|
| `uuid` | The `candidate_uuid` |

### Response — 200 OK

```json
{
  "notes": [
    {
      "id": "note_7f3e2a1b9c4d5e6f",
      "candidate_uuid": "b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6",
      "author": "frontend",
      "content": "Strong KRAS background. Has Phase 1 experience at MSKCC.",
      "created_at": "2026-04-29T15:10:00Z",
      "updated_at": "2026-04-29T15:10:00Z"
    }
  ]
}
```

## PUT /v1/candidates/\{uuid\}/notes/\{note_id\}

Update the content of an existing note.

**Auth required:** Yes

### Path Parameters

| Param | Description |
|-------|-------------|
| `uuid` | The `candidate_uuid` |
| `note_id` | The `id` returned when the note was created |

### Request Body

```json
{
  "content": "Updated note text."
}
```

### Response — 200 OK

```json
{
  "status": "updated"
}
```

---

## DELETE /v1/candidates/\{uuid\}/notes/\{note_id\}

Delete an analyst note.

**Auth required:** Yes

### Path Parameters

| Param | Description |
|-------|-------------|
| `uuid` | The `candidate_uuid` |
| `note_id` | The note ID to delete |

### Response — 200 OK

```json
{
  "status": "deleted"
}
```
